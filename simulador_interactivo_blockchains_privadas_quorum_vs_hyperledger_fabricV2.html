Quorum (Enterprise Ethereum)

          
    
            
  • Dirección: Hexadecimal de 20 bytes (0x71C9...989A).
    • 
            
  • Acceso de Red: Lista blanca de nodos (permissioned-nodes.json).
    • 
            
  • Consenso: QBFT (vota cada bloque 2/3) o Raft (vota solo para elegir Líder; el Líder replica bloques vía AppendEntries).
    • 
            
  • Privacidad: Libro público con hashes + estado privado cifrado punto a punto por Tessera.
    • 
          

        


        

          
Hyperledger Fabric (Linux Foundation)

          
    
            
  • Dirección: NO usa 0x...; usa Certificados X.509 + Org1MSP.
    • 
            
  • Acceso de Red: Autoridad Certificadora (CA) y MSP verifican cada firma.
    • 
            
  • Privacidad: Canales físicamente aislados (sub-blockchains independientes).
    • 
            
  • Ejecución: Execute → Order → Validate (paralelo en contenedores Docker).
